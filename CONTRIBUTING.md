# Contributing

Thank you for helping improve the Mobile Application Development playbook.

## Contribution guidelines

- Keep changes relevant to this project only.
- Preserve the stage sequence unless a documented improvement justifies a change.
- Keep stage prompts actionable, testable and specific to this platform.
- Update `STAGE_INDEX.md`, `WORKFLOW_OVERVIEW.md` and `README.md` when stages change.
- Validate all relative Markdown links before submitting changes.
- Do not add secrets, private credentials or proprietary user data.
- Explain the motivation, impact and validation performed in the pull request.
