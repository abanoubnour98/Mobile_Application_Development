# Security Policy

This repository contains workflow guidance and prompt templates for mobile application development.

## Reporting a problem

Do not publish secrets, credentials, private keys, signing certificates, production data or exploitable vulnerabilities in public issues. Use the repository owner's private reporting channel for sensitive reports.

## Safe usage

- Review generated code and commands before running them.
- Do not provide AI agents with production credentials unless a controlled, authorized secret-management mechanism is in place.
- Require explicit approval before deployment, destructive operations, purchases or public releases.
- Verify dependencies and official platform guidance before adopting security-sensitive recommendations.
