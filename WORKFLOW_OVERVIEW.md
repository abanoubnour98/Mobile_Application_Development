# Mobile Application Development — Workflow Overview

This document describes the stages, specialist skills and expected outputs for this standalone project. It does not depend on another platform workflow.

| Stage | Focus | Core skills | Deliverables |
|---:|---|---|---|
| 01 | Mobile Product Discovery & User Research | Product Discovery, Mobile User Research, Business Analysis, Market Research, Product Strategy | Mobile product brief |
| 02 | Platform Strategy & Requirements | Requirements Engineering, iOS/Android Platform Analysis, Native/Cross-Platform Evaluation, Device Compatibility, Release Strategy | Platform decision matrix |
| 03 | Mobile UX Research & Interaction Design | Mobile UX, Task Analysis, Navigation Design, Gesture Design, Usability Testing, Accessibility | Mobile journey maps |
| 04 | Mobile UI Design & Design System | Mobile UI Design, Design Systems, Figma, Native Design Guidelines, Responsive Layouts, Accessibility | High-fidelity mobile screens |
| 05 | Mobile Architecture & Technology Selection | Mobile Architecture, Swift/Kotlin/Flutter/React Native Evaluation, Domain Modeling, State Management, ADR Writing, Threat Modeling | Architecture decision records |
| 06 | Repository, Build System & Developer Setup | Git, Xcode/Android Tooling or Cross-Platform Toolchain, Dependency Management, CI, Code Signing Setup, Testing Automation | Repository and module structure |
| 07 | App Foundation, Navigation & Lifecycle | Mobile UI Engineering, Navigation, Lifecycle Management, State Restoration, Localization, Logging | Runnable app foundation |
| 08 | Feature Development & App State | Mobile Development, Swift/Kotlin or Selected Framework, State Management, Domain Logic, UI Testing | Implemented mobile features |
| 09 | Backend, Local Data, Offline & Synchronization | API Integration, Local Persistence, Offline-First Design, Sync, Caching, Conflict Resolution | API client and data layer |
| 10 | Native Capabilities, Permissions & Notifications | iOS/Android APIs, Permissions, Push Notifications, Camera/GPS/Bluetooth/Files as needed, Deep Links, Background Tasks | Native integration modules |
| 11 | Mobile Security & Privacy Engineering | Mobile Security, OWASP MASVS/MASTG, Secure Storage, Keychain/Keystore, Network Security, Privacy Engineering | Mobile security assessment |
| 12 | Accessibility, Performance, Battery & Reliability | Mobile Performance, Profiling, Accessibility, Battery Optimization, Crash Diagnostics, Device Compatibility | Performance baseline |
| 13 | QA, Device Matrix & Release Candidate | Mobile QA, Unit/Integration/UI Testing, Device Farm, Exploratory Testing, Security Testing, Regression | Test plan and results |
| 14 | Store Readiness, Compliance & Listing Assets | App Store / Google Play Operations, Policy Review, Privacy Documentation, ASO, Release Management | Store listing metadata |
| 15 | Release, Rollout & Post-Launch Operations | Mobile Release Engineering, Store Console Operations, Crash Analytics, Feature Flags, Incident Management | Published release |
| 16 | Analytics, Feedback & Continuous Improvement | Mobile Product Analytics, Crash Reporting, UX Analytics, Experimentation, Customer Support, Roadmapping | Product KPI dashboard |
