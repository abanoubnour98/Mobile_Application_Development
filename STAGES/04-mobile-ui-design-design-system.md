# Stage 04 — Mobile UI Design & Design System

**Track:** Mobile Application Development  
**Objective:** Create production-ready iOS/Android visual designs and reusable components.

## Required specialist skills

- Mobile UI Design
- Design Systems
- Figma
- Native Design Guidelines
- Responsive Layouts
- Accessibility

## Dependencies / previous inputs

- Stage 03 wireframes
- Brand identity
- iOS/Android guidelines

## Execution checklist

1. Define tokens, typography, spacing, color, iconography and component variants.
2. Design platform-appropriate navigation, app bars, forms, lists, cards, sheets, dialogs and notifications.
3. Specify safe areas, status/navigation bars, keyboards, orientation and dynamic text behavior.
4. Cover light/dark themes, focus, pressed, disabled, loading and validation states.
5. Create layouts for supported phones and tablets.
6. Prepare annotated design handoff and reusable component inventory.

## Required deliverables

- [ ] High-fidelity mobile screens
- [ ] Design system
- [ ] Component library
- [ ] Platform-specific design variants
- [ ] Prototype and handoff

## Acceptance criteria

- [ ] All core flows and states are covered.
- [ ] Layouts adapt to supported screen sizes and system settings.
- [ ] Designs meet accessibility and platform expectations.

## Professional tips and common mistakes to avoid

- Use actual device frames and content lengths.
- Do not simply shrink desktop layouts to mobile dimensions.
